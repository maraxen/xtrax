Negotiable: score_fn's real behavior (synthetic-and-decoupled vs. reading real artifacts), whether the pass-campaign's 2nd candidate is calibrated to also genuinely win the ratchet (not just stats-battery), concrete_inputs' actual values, whether git scratch-repo setup is shared or per-campaign, ratchet_ref_name uniqueness scheme, and current_config's contents.
