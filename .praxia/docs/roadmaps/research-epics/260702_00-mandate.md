## Human (HITL) gates

Seven gates, each bound to a DAG node (freshness for the #2181 gates rides the T3-05 primitive):

1. **Roadmap approval** — this document + DAG docs, after adversarial review (you are here).
2. **#2181 constitution authorship** (T2-28 / AC-21) — the immutable top-level rules (research
   agenda, budgets, error handling) are human-authored before any loop runs.
3. **Evaluator / splits / metric change** (T2-29 / AC-22) — any change to evaluator code, splits, or
   metric definitions is human-gated: *the agent never approves its own judge*. Standing runtime gate
   (fires on evaluator-change events), forcing a closure-hash re-lock before the changed evaluator is
   trusted.
4. **Promotion-to-main review** (T2-30 / AC-23) — no evolved candidate merges without human
   engineering review.
5. **Scope expansion** (T2-31 / AC-24) — adding evolve-block surface area or new effectful tools
   (incl. island-phase entry) = human gate.
6. **Campaign approval + kill switch** (T2-32 / AC-25) — every confirmatory campaign start is
   human-approved AND the watchdog's kill authority is unrevokable by the loop; humans hold it. These
   two are the **single combined DAG node T2-32**.
7. **T3 phase-2 entry** (T3-P2G, HITL gate 7) — investing in praxia-side strict dispatch is a human
   decision fed by the AC-V2 probe result.

## Metrics of success / fail-fast conventions (roadmap-level)

- **Every gate in every DAG states its success metric AND its fast/loud failure behavior** —
  inherited from the audit-framework template (deterministic spine, probabilistic leaves).
- T1: BatchPlan parity (zero divergence), ordering preserved under nested vmap-of-scan stress
  (fail on FIRST out-of-order record), authoring benchmark reports ABSOLUTE faithfulness (fails
  if only mode-vs-mode delta), compiler-boundary grep-gate (CI exit 1).
- T2: fitness scalars ONLY from the SHA-closure-pinned evaluator (AC-7 hashes the complete
  closure); synthetic ground-truth sanity check must pass before any campaign (BATHOS rule);
  statistical gates at campaign conclude: WR≥0.6, BP≥0.2, Cohen's d≥0.2, α=0.05 Holm, ≥3 seeds
  ICC>0.990 (hard block for confirmatory); no LLM judgment inside the loop.
- T3: install/export drift → CI exit 1 with diff; human-gate records derive from TTL
  attestation + invalidate-only probe (the n9-staleness defect is structurally killed);
  toolless-strict dispatch impossible by construction.
- **No silent caps anywhere:** every deferred/skipped item is a named decision in a spec's
  Decision Log, not an omission.
