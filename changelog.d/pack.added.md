- `xtrax.pack`: packs a completed loose-file unit into `members.tar.zst` + `members.idx.json` + its `unit.json` record, with random access to each member. The format is alynxr's `unit_pack` (one zstd frame per USTAR member, plus a frame index), so packs read across both. `write_unit_record` commits a unit (the `CommitRecord` fields; `record_digest` equals `zarr_commit`'s over the same core) and `content_digest` is the same loose or packed. Packing is a five-step crash-safe commit under a per-unit lock, finished by `pack_sweep`; index keys are not trusted, and a loose file is deleted only when byte-identical to its packed copy. zstd comes from `compression.zstd` (3.14), `zstandard` (the new `xtrax[pack]` extra), or the `zstd` CLI, one process per member; with none, `CodecUnavailable` (an `OSError`) is raised. The core is stdlib-only and Python 3.9 compatible; `node_source()` returns it for embedding. `xtrax.run.unit_index_adapters.UnitJsonAdapter` indexes these records.
