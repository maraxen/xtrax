- `xtrax.run.commit_key(..., verify_duplicate=False)`: with `verify_duplicate=True`, a key already committed with the same `input_digest` but different content raises `CommitConflictError` instead of returning `Duplicate`. Off by default in this minor and on by default in the next; a nondeterministic producer that relied on `Duplicate` will then raise. `SinkSpec.verify_duplicate` passes it through durable `ZarrStagingSink` drains.
- `xtrax.run.quarantine(store, key)` and `quarantine_root(store)`: move a damaged or uncommitted key to `<store>.quarantine/`, never deleting it; a key that turns out to be valid (a racing writer) is restored and `QuarantineRaceError` is raised. Lifted from alynxr's fold-stats array commit.
