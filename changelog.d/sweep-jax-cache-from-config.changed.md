- `xtrax sweep` (deprecated) no longer hard-codes `jax_compilation_cache_dir = ".xtrax/jax_cache"`; it calls `xtrax.jax_cache.configure()`. Behaviour change: the sweep's cache is off unless a project or user config sets `jax_compilation_cache_dir` (xtrax's own `pyproject.toml` now sets `.xtrax/jax_cache`), the path is relative to the declaring `pyproject.toml` rather than the current directory, and entries live in the `jaxlib-<version>/cpu-<hash>` namespace subdirectory. To keep the old behaviour add `[tool.xtrax]` with `jax_compilation_cache_dir = ".xtrax/jax_cache"` and `jax_cache_namespace = "none"` to the project's `pyproject.toml`.
