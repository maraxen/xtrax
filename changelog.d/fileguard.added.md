- `xtrax.fileguard`: file-count (inode) guard for shared scratch, lifted from alynxr's `storage.py`. `FileCapGuard` reads the real quota (`lfs quota` on Lustre, which is refused rather than replaced by `df -i`; `df -i` elsewhere), refuses a write whose projected count exceeds `cap_fraction` of the limit, and re-reads every `reread_every` files. On a setgid Lustre directory it also enforces the owning group's quota. `check_concurrency_slack` refuses at plan time when N concurrent guards could jointly overshoot. Events go through an injectable emitter (`cisternal.emit_event` when installed, else logging). The core is stdlib-only and Python 3.9 compatible; `node_source()` returns it for embedding in cluster scripts.
