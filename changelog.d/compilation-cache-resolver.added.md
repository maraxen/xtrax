- `xtrax.compilation_cache`: one resolver for the JAX persistent compilation cache. Placement (where) resolves from `--compilation-cache`, `XTRAX_COMPILATION_CACHE_DIR`, `JAX_COMPILATION_CACHE_DIR`, then `compilation_cache_dir` in `~/.config/xtrax/config.toml`; policy (whether) from `XTRAX_COMPILATION_CACHE`, then `[tool.xtrax] compilation_cache = "on" | "off"`. `enable_compilation_cache()` applies the decision, reports which layer decided each axis, and leaves JAX untouched when nothing is configured. `CacheDecision` records it for run summaries.
- `xtrax run` and `xtrax campaign run` take `--compilation-cache PATH|off`; `LocalSequentialExecutor` and `LocalProcessPoolExecutor` take `cache_dir` as a path, `"off"` or a resolved `CacheDecision`. Slurm array scripts bake the project's cache policy, never a local directory.
