- `xtrax.agent` is one startup for consumer CLI and MCP entry points: `run_cli(app)` and `serve(server)` apply the persistent JAX cache, then start cisternal telemetry (unless `telemetry=False`), then dispatch. A cache error exits 2 with a stderr line; a missing cisternal exits 1 with a hint naming `xtrax[plugin]`. `start()` runs the two stages and returns the cache setting without converting errors.
